# huan-an-comment-ops

跨平台评论运营与社区风险控制。当创作者需要批量分诊评论、设计作者回复、管理争论、判断评论增长是否健康、从评论提炼内容线索，或复盘评论区运营时使用。也用于“该不该回、怎么追问、何时收口、何时隐藏或升级人工”等问题。不用于刷量、互赞互评、伪装路人、挑衅引战或自动执行平台写操作。

## 安装

```bash
npx -y skills add hosemo-hub/huan-an-comment-ops -g --all
```

## 使用

安装后，可以这样开始：

> 使用 $huan-an-comment-ops 分诊这些评论或线程。先区分证据状态与风险，再给出最小充分动作、公开回复草案和停止条件；不要把建议动作写成已执行事实。

## 运行依赖

- 支持 Agent Skills 的客户端
- Python 3（用于运行 Skill 内脚本）

## 设计边界

- 优化有价值的参与，不优化裸评论数；
- 按线程判断，不机械逐条回复；
- 先安全、再增长；
- 默认只分析与拟稿，不自动在平台回复；
- 区分真实动作、建议动作、模拟动作和未知；
- 不依赖任何私有项目、客户目录或本机路径。

## 内容与验证

仓库包含运行文件、两个确定性统计脚本和匿名化公开回归案例。真实用户名、原评论全集、截图、本机路径、签名链接、内部实验记录和私有账号数据不发布。

当前版本为 `0.1.0-trial`：已通过结构、脚本和跨平台行为冒烟；尚未证明能提升真实流量、评论或涨粉。证据范围与未知见 [evidence-base.md](docs/evidence-base.md)。
