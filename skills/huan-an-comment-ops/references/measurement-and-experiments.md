# 测量与实验

## 不用单一“评论质量分”

评论区同时包含增长、知识、关系和伤害。用向量记录，避免一个总分掩盖风险：

- `constructive_ratio`：story/question/correction/insight/dissent 中有实质内容的占比；
- `social_ratio`：affiliation/play 的占比；
- `noise_ratio`：spam、复制互赞和无关导流占比；
- `harm_ratio`：harm 占比；
- `threaded_ratio`：有至少一条回复的主评论占比；
- `author_reply_rate`：作者回复的可回复主评论占比；
- `substantive_author_reply_rate`：作者回复中增加承接、信息、澄清、规范或有效追问的占比；
- `new_information_rate`：抽样线程中至少出现一次新事实、条件或经历的占比；
- `stop_breach_count`：已命中停止条件但仍继续推动的次数。

样本太小时同时报告分子和分母，不只报百分比。

## 识别“低粉爆款”

只有同时具备以下证据，才标为 `verified-low-follower-breakout`：

1. 发布时或接近发布时的粉丝数证据；
2. 目标作品指标；
3. 同账号至少 5 个、优先 8–12 个相邻作品的同口径基线；
4. 评论线程样本。

若只有当前粉丝数，不能倒推出发布时粉丝数。首篇爆款但当时粉丝未知，标为 `first-post-breakout-follower-unknown`。

账号内异常优先用稳健指标：

```text
breakout_multiple = target_metric / median(baseline_metrics)
```

同时报告基线数量、范围、中位数和 IQR。不要把不同平台的播放、点赞、收藏、投币硬加成一个分数。

## 发现集与盲测集

- 发现集：用于提炼分类、状态机和平台差异；
- 盲测集：定稿前不用于改规则，只用于独立测试；
- 回归集：把人工纠正、失败和安全边界固化为长期测试。

## 原互动与模拟互动比较

不能观测模拟回复真正发布后的反事实结果，因此比较的是“决策质量”，不是实际涨粉效果。对原作者动作与 Skill 动作匿名为 A/B，按 0–2 分评：上下文贴合、信息增量、旁观者价值、规范信号、升温风险（反向）、隐私与安全、平台适配、停止条件清晰。

至少一名人工评审不知道哪条来自 Skill。报告逐项差异，不只报均分。

## 在线对照实验

原 Skill 与候选 Skill 接收相同新评论、相同上下文、相同允许动作。先分别输出，再盲标 A/B，由人工选择实际动作。回填：选择理由、是否发布、后续 24h/7d 线程新增信息、伤害/垃圾变化和人工成本。

候选只能在跨至少两个平台、多个内容类型的真实新样本中持续胜出，且安全无回退后升格。单次高分不升格。
