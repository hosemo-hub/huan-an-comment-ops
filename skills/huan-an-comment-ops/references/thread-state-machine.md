# 线程状态机

## 贡献类型

| 类型 | 识别信号 | 默认价值 | 常见动作 |
|---|---|---:|---|
| story | 具体人物、时间、行为、后果 | 高 | 精确承接；追问一个关键细节 |
| question | 请求事实、方法、选择条件 | 中到高 | 直接回答；必要时澄清条件 |
| correction | 指出事实、表述或来源错误 | 高但需核验 | 感谢；核验；公开更正 |
| insight | 提炼规律、条件或反例 | 高 | 搭桥或邀请举例 |
| affiliation | 认同、支持、身份归属 | 中 | 点赞或短承接，不必强追问 |
| play | 玩梗、接梗、轻社交 | 低到中 | 顺势但不劫持主题 |
| dissent | 有理由的不同意见 | 高 | 澄清分歧对象；邀请条件或反例 |
| provocation | 只刺激、贴标签、抢最后一句 | 低/风险 | 不奖励；必要时规范提示 |
| spam | 互关互赞、导流、复制、无关广告 | 负 | 忽略、隐藏或举报 |
| harm | 威胁、隐私、仇恨、骚扰、自伤他伤等 | 高风险 | 立即安全处置 |

同一评论可有一个主类型和一个次类型，不要为凑标签多标。

## 线程阶段

- `seed`：一个新贡献，尚未形成互动。判断是否值得让旁观者看见。
- `expanding`：参与者不断增加经历、问题、证据或有用玩梗。可具体追问、搭桥或置顶。
- `contending`：存在实质分歧，双方仍回应论点。澄清争点和条件，不宣布谁赢。
- `polarizing`：阵营标签、道德判决、围攻信号上升。减少开放追问，做一次规范提示或事实澄清。
- `derailing`：互关、导流、身份审判、无关争执或重复梗占据线程。停止奖励偏航。
- `acute-risk`：具体威胁、隐私、违法、自伤他伤、未成年人性化或持续骚扰。覆盖增长目标。
- `exhausted`：连续两轮没有新事实，或公开说明已足够。收口或不再回复。

```text
seed -> expanding -> contending -> polarizing -> acute-risk
  |         |            |             |
  +------> exhausted <----+-------------+
            ^
derailing--+
```

状态可以跳跃；一条隐私威胁可从 seed 直接进入 acute-risk。评论多不代表 expanding，复制式互赞应进入 derailing。

## 争论是否值得继续

同时满足以下三项才继续：

1. 至少一方仍在增加事实、条件或反例；
2. 旁观者能从下一轮获得信息或规范价值；
3. 风险可控且作者没有被迫承担专业处置职责。

否则收口、观望或安全处置。
