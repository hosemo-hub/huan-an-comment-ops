# 豆包手机端：安装并使用「评论罗盘」

技术安装名：`huan-an-comment-ops`。

这套路径来自当前豆包手机端“工作任务”界面的实际演示：切到工作任务，让云电脑替你完成仓库安装；安装后从会话底部直接选技能。用户不需要手动复制 `SKILL.md`、`references/` 或脚本文件。

## 1. 切到工作任务

1. 打开豆包 App，新建对话。
2. 点左下角当前显示的 **快速**。
3. 在弹出的模式里选择 **工作任务 Auto**。
4. 看一眼底部的 **云电脑**，确认它显示在线。

## 2. 发一句安装指令

把下面这段原样发给豆包：

```text
请把这个仓库安装成可调用的技能包：
https://github.com/hosemo-hub/huan-an-comment-ops

安装完成后告诉我：
1. 安装到了哪里；
2. 识别到的技能名称；
3. 是否需要新开一个工作任务会话才能完整生效。

最后请让我上传一张评论区截图测试。
```

安装过程会由工作任务和云电脑完成。等它明确回复“安装完成”，再进入下一步。

## 3. 从底部“技能”调用

1. 查看当前会话底部是否出现 **技能**。
2. 点开后搜索或选择 `huan-an-comment-ops`；对外也可以记作“评论罗盘”。
3. 如果还没出现，新建一个 **工作任务 Auto** 会话，再打开技能列表。
4. 把评论截图和作品链接扔进去，之后只说：

```text
处理
```

电脑端登录同一豆包账号，也能继续使用这台云电脑。需要让自己的电脑参与工作时，点底部 **云电脑 / 工作设备**，选择“添加我的电脑”并按豆包提示连接。

## 4. 最傻瓜的输入

直接扔进去两样东西：

- 一张或多张评论区截图；
- 对应的作品链接。

然后说：

```text
处理
```

评论罗盘会在内部完成父子评论还原、线程判断、安全检查和动作选择，默认只给你看：判断、动作、需要时的回复、什么时候停。

你也可以继续附上：

- 公众号文章、网页文章或帖子链接；
- 短视频文稿、字幕或逐字稿；
- 抖音、小红书、视频号、B站或 X 的作品链接；
- 账号语气、这次运营目标和允许执行的动作。

如果当前模型能直接读取作品链接，就让它连同评论一起判断；如果它不能读取某个平台的视频，再补文稿、字幕或几个关键画面。不要因为读不了视频，就放弃先处理截图里的评论关系。

## 5. 一个完整测试指令

只有你想明确目标、允许动作和输出内容时，才需要用这个建议版：

```text
使用评论罗盘。

附件：评论区截图.png
作品链接：https://...
这次目标：找出真实问题和反例，不追求把每条都回完。
允许动作：回复、点赞、观察、收口、人工处理。

请输出：
1. 你从截图和链接中看见的事实；
2. 重点线程和判断；
3. 每条线程的最小动作；
4. 需要时的回复草案；
5. 为什么这样做；
6. 什么时候停止继续回复。
```

## 6. 如果当前账号没有“工作任务”或“技能”

先更新豆包 App，并确认使用的是支持工作任务的账号。暂时没有入口时，也可以在普通对话里上传评论截图和作品链接，再粘贴上面的完整测试指令；等入口开放后，再按前面的方式安装成可调用技能。
