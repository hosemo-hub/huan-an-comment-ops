# Evidence base and limits

Version 0.1.0 is a Trial candidate derived from a maximum-variation discovery sample across public WeChat-derived project data, Xiaohongshu, Bilibili, YouTube and Reddit comment structures.

The transferable core is limited to evidence separation, thread-first triage, minimum sufficient action, explicit stop conditions, and safety overriding growth. Platform features, audience cultures and recommendation effects are not assumed to transfer.

Public examples and regression cases are anonymized or structurally paraphrased. Private comments and identities are not included.

Key public references:

- YouTube comment settings and moderation: https://support.google.com/youtube/answer/9483359
- Bilibili user agreement, section 5.8: https://www.bilibili.com/blackboard/protocal/licence.html
- Social media firestorms, purpose and tone: https://jmis-web.org/articles/1581
- Digital social norm enforcement: https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0155923

Known gaps: no production A/B result; incomplete publication-time follower snapshots; no qualifying Douyin, TikTok or WeChat Channels corpus; no claim that author replies cause recommendation growth.
